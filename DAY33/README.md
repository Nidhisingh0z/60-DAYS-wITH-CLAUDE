
Day 33
Build a Media Integrity Analyzer
Learn to evaluate information before believing it
A quick tour of what's inside:

Concept-first flow: each challenge opens with a plain-language explainer (what it is, why it matters, everyday relevance) before any interaction.
Discovery, not testing: users vote/react first, then reveal compares their gut read to the underlying analysis — feelings are never marked "wrong," only factual phrase-spotting is scored.
3 rotating scenarios each for headlines and emotional posts, so "Replay" gives genuinely new content without repeats.
Live metrics strip (Headline Accuracy, Source Reliability, Emotional Manipulation, Audience Targeting) fills in as you complete each challenge.
Dashboard with an animated integrity gauge, dynamic biggest red flag, personalized "what you learned," and three fixed habits — plus Replay and Start Over.
Pure vanilla HTML/CSS/JS, single file, offline-safe, no external fonts/images/APIs, respects prefers-reduced-motion, and uses real <button> elements with visible focus states for accessibility.
