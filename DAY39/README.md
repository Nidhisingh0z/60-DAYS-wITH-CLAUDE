# 📄 PDF Splitter & Merger

A premium **browser-based PDF utility** built as a single-page interactive application.  
This project was developed on **Day 39** of my coding journey.

---

## 🚀 Features

### 🔹 PDF Splitter
- Upload a PDF and automatically detect total pages.
- Visual **page thumbnails** with preview before splitting.
- Split by:
  - Custom page ranges
  - Specific page numbers
  - Every N pages
  - Extract selected pages
- Create multiple split ranges in one operation.
- Validate inputs and highlight errors.
- Preview resulting document structure before processing.

### 🔹 PDF Merger
- Upload multiple PDFs via **drag-and-drop** or file selection.
- Sort and reorder files with drag-and-drop.
- Display file list with page counts and previews.
- Show total files, total page count, and estimated output.
- Merge into a single polished PDF with easy download.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** Browser-compatible PDF libraries (e.g., `pdf-lib`, `pdf.js`)
- **Processing:** 100% client-side (no server uploads)
- **Offline Support:** Works after initial load

---

## 🎨 UI/UX Highlights
- Responsive layout with **dark mode**
- Drag-and-drop uploads
- Smooth animations & micro-interactions
- Accessibility features & keyboard shortcuts
- Intuitive error handling and loading indicators
- Commercial-grade design with modern typography

---

## 📂 Project Structure
- `index.html` → Single-page application
- Inline CSS & JS for portability
- No backend dependencies

---

## ⚡ How It Works
1. Open the application in your browser.
2. Choose **Splitter** or **Merger**.
3. Upload PDFs and interact with the visual interface.
4. Process and download results instantly.
