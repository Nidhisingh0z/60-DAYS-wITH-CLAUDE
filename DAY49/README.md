Day 49/100: Built a Personal AI Playbook 🛠️

You don't have a prompting problem. You have a "rewriting the same prompt every time" problem.

I use Claude every day for writing code and debugging — and my real bottleneck was never getting AI to write code. It was getting AI code I didn't have to heavily edit afterward.

So today's build is a tool for exactly that: a Personal AI Playbook — turning my own AI habits into reusable workflow systems instead of one-off prompts I retype from memory every session.

What's inside:

→ Ready-made workflows for writing new features, debugging, and — the one I use most — fixing AI code that's close but not quite right. Targeted fixes, not full rewrites.

→ A Prompt Builder that assembles prompts from real building blocks (role, objective, context, constraints, reasoning strategy, output format, quality checks) with a live preview as you go.

→ A Loop Builder that wraps any prompt with a goal, evaluation criteria, and stop conditions — so Claude can check its own work instead of me babysitting every attempt.

→ Everything saved locally. No backend, no accounts. Dark mode, keyboard shortcuts, import/export.

The lesson that stuck with me: most people lose time re-explaining context to AI every single session. A prompt gets used once. A system gets used for months.

Built as a single self-contained HTML file — no frameworks, no dependencies.
